# qwen3.8-max 图像输入的探索性配对实验

**本次未观察到图片带来的额外改善。** 纯文本组有 2/24 个严重错误，文本加图片组有 3/24 个；主比较未达到预定推进条件（`not_met`）。纯文本组相对旧 VNTL 的改善属于部署方案的描述性比较，不能归因于图像。

## 研究问题与设计

研究问题：在同一 API 模型和文字上下文下，加入整页图片能否减少严重翻译错误？

- **A：纯文本**，提供目标区域日文、目标编号与整页日文上下文。
- **B：文本＋图片**，沿用 A 的文字条件，增加标注目标区域的整页图片。
- **VNTL ctx0：历史基线**，复用同一区域的旧译文，在本轮重新评分；其模型、提示和上下文方案与 A/B 不同。

A/B 均使用 `qwen3.8-max`，`max_completion_tokens=256`、`enable_thinking=false`。英文参考译文和人工标签不进入模型输入。样本为 24 个已见区域、23 页，按旧标签选出 12 个严重错误和 12 个正常对照。本轮 VNTL 重新评分有 14 个严重错误，但原 12/12 分组保持不变。样本刻意富集既有错误，以下比例不是作品或产品总体错误率。

## 样本替换与探索性范围

首轮在已获得 18 个完整 A/B 配对、尚未做人评或效果分析时，因 `tojime_no_siora:p0010:t010` 的图片请求被服务商拦截而停止。该区域是原定强制纳入的案例之一；随后将其整页图片、日文和目标编号一起替换。**原固定样本清单未完成，本报告是修改样本后的探索性结果。**

备用选择规则在选样前固定，不使用本轮模型输出或新评分：与原区域同作品、同旧严重错误标签，并匹配原 `reference/alignment` 优先级；区域及其页面均不在原清单中；旧 VNTL 译文、日文与参考英文均有效且非空。原区域的错误类型 `tags` 为空，严重错误标签为 `true`；优先级按原规则记为 false，不据此推断它不存在指代或跨泡错误。合格项按区域 ID 排序后以 seed=2026102104 选择，实际仅有 1 个合格项；参考英文仅用于合格性检查。

其余 23 个区域、条件参数和 A/B 顺序不变。原 36 个有效响应直接复用，补充替换区域及其余未完成区域的 12 个响应，得到当前 48 个有效 API 候选。原被拦截样本不计入当前 24 区，也不记为成功；替换结果不能消除服务商筛选造成的选择偏差。

## 评分与统计

三组共 72 个候选由一名评审评分。严重错误、人物／动作指代、跨气泡对应及动作方向四类判断均无缺失；没有第二评审或评审一致性估计。

主比较固定为 B−A。按实际页 ID 配对 bootstrap 2,000 次（seed=2026102102），保留页内区域及配对关系，用线性插值的 2.5/97.5 百分位构成 95% 区间。差值以百分点表示，正值表示候选组错误更多。统计规则要求响应有效且相关标签非缺失；当前所有候选有效，24 对完整，没有因失败或缺评排除的区域。区间未计入评审误差，也不能消除选样偏差。

## 主要结果

| 组别 | 严重错误 | 严重错误率 | 95% 区间 | 人物／动作指代错误 |
|---|---:|---:|---:|---:|
| A：纯文本 | 2/24 | 8.33% | [0.00, 21.74]% | 2/24 |
| B：文本＋图片 | 3/24 | 12.50% | [0.00, 26.09]% | 3/24 |
| 旧 VNTL ctx0 | 14/24 | 58.33% | [40.00, 76.02]% | 12/24 |

**主比较 B−A：**严重错误率差为 **+4.17 个百分点 [0.00, 13.04]**，修复 0 个、退化 1 个、净减少 −1 个；两组共同严重错误 2 个。固定正常对照中，A 为 0/12、B 为 1/12 严重错误。区间包含零，不能宣称图片会稳定增加严重错误。

预定推进条件要求：至少 20/24 个完整配对、全部 12 个正常对照完整、B 净减少至少 3 个严重错误，且正常对照无新增严重错误。完整性条件满足，后两项不满足，因此判定为 `not_met`。

**A−VNTL 描述性比较：**严重错误率差为 **−50.00 个百分点 [−69.23, −30.43]**，修复 12 个、退化 0 个。人物／动作指代错误率差为 **−41.67 个百分点 [−64.00, −17.39]**：VNTL 的 12 个指代错误中修复 11 个，同时新增 1 个，净减少 10 个。模型、提示及上下文均不同，不能将改善单独归因于模型规模或某项输入变化。

三组跨气泡对应错误均为 0，本轮无法评价其修复效果；零事件不证明真实风险为零。三组动作方向错误均为 1，A/B 未修复同一条错误；相对 VNTL 则各有一次修复和一次退化，总数相同不代表错误完全相同。

## 案例

下表展示一例 VNTL→A 改善、唯一的 A→B 严重退化，以及全部两组共同严重错误。判断来自本轮评审，完整译文与备注保存在逐条记录中。

| 区域 | 观察 |
|---|---|
| `rasetugari:p0005:t003` | 「家族を悪鬼に喰われて以来」：VNTL 译为 “my family”，A 改为 “his family”，修正了叙述中的亲属指向。 |
| `rasetugari:p0007:t001` | 「さま...」：A 保留 “…sama…”，B 译为 “Lord…”，评审认为误解了跨泡呼唤兄长的称谓。这是唯一的 A→B 严重退化，也属于原正常对照。 |
| `rasetugari:p0026:t003` | 「幻術とはいえ妹の顔を...」：A/B 均使用 “my sister's face”，评审认为把少年的妹妹误归为当前说话人的妹妹。 |
| `tojime_no_siora:p0023:t006` | 「つっつけようったって...」：A/B 均未正确还原追踪者与被追踪者的关系，属于共同严重错误。 |

## 结论与数据

当前样本不支持同一 API 模型加入图片后获得额外收益。纯文本组相对旧 VNTL 的改善值得进一步验证，但样本已见、错误富集、替换过一例且仅有一名评审，结论不能推广为总体翻译质量，也不能据此判断图像在其他任务中无效。
