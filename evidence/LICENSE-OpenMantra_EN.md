**Language / 语言**: English | [简体中文](LICENSE-OpenMantra.md)

The `cases.csv` files and some JSON files under `results/` contain OpenMantra's Japanese source text and English reference translations.

- Dataset: [OpenMantra](https://github.com/mantra-inc/open-mantra-dataset), revision `59341ad922284a8be219b7784feb5a79779a1447`, by Mantra Inc.
- Paper: Ryota Hinami et al., *Towards Fully Automated Manga Translation*, AAAI 2021.
- License: [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/), non-commercial use only.
- Changes: only the text fields of the test works `tojime_no_siora` and `rasetugari` are kept, stored side by side with this project's model outputs, OCR results and scores; no manga images are included.

The model outputs, scores and statistical results in this directory were generated by this project; the rights in the dataset's source text and reference translations belong to the original rights holders.
