# 本地漫画翻译对照实验方法

本文件概括 `openmantra-v1` 的四条件实验。配置、测试页及人评抽样见[冻结记录](freezes/openmantra_v1_test.json)，结果见[摘要](SUMMARY.md)。研究目标是在固定文字框下，区分 OCR 输入、邻近上下文与本地部署模型选择对翻译结果的影响。

## 样本与控制条件

数据来自 OpenMantra，按作品划分开发集和测试集。选取既定作品的前 N 个连续页面，不是对漫画总体的随机抽样；测试页按元数据选定，不根据模型效果换页。

| 用途 | 作品与页面 | 区域数 |
|---|---|---:|
| 开发与调试 | tencho_isoro，p0001–p0012；其中前 3 页用于初步运行检查 | 96 |
| 正式测试 | tojime_no_siora，p0001–p0024 | 224 |

配置与样本在正式测试前冻结；参考英文不进入模型输入。看过测试结果后的修改另列探索性，不覆盖原结果或继续称为独立确认。

| 条件 ID | 模型 | 当前区域日文 | 邻近日文预算 |
|---|---|---|---:|
| vntl-gold-c0 | VNTL Llama3 8B，Q4_K_M | 官方日文 | 0 |
| vntl-ocr-c0 | 同一 VNTL | 同一官方文字框的 Manga-OCR 输出 | 0 |
| vntl-gold-c1200 | 同一 VNTL | 官方日文 | 1,200 字符 |
| qwen-gold-c0 | Qwen2.5-3B-Instruct，无 LoRA | 官方日文 | 0 |

共同设置为逐区域翻译、最多 256 个输出 token、失败最多重试一次；关闭续句合并、英文历史、术语提取和注入，使用独立空数据库。VNTL 使用原生提示格式、temperature=0、repeat_penalty=1、2,048 token 上下文；Qwen 使用原生 chat template 与 greedy 解码，上限为 8,192 tokens。参数量、训练、量化和提示格式不同，因此模型间比较只代表这些部署组合。

`gold` 表示官方日文和文字框；阅读顺序使用未人工核实的标注序号（`annotation_index_unverified`）。OCR 条件不以正确日文填补识别失败。所有条件共享文字框与排序代理，不能据此评价实际检测、阅读顺序、清字和排版后的端到端质量。

## 指标与统计方法

两个主要对比为 `vntl-ocr-c0 − vntl-gold-c0`（OCR 输入影响）和 `vntl-gold-c1200 − vntl-gold-c0`（上下文影响）；`vntl-gold-c0 − qwen-gold-c0` 为次要部署参照。

翻译指标为 corpus chrF++，使用 SacreBLEU 2.6.0（char_order=6、word_order=2、beta=2）。按作品计算后取宏平均；本次每个 split 仅一部作品，实际为该作品的 corpus 分数。仅参考日文或英文原本为空的区域不参与评分；翻译失败保留为空译文，计入分母。测试中 Qwen 的 `p0013:t003` 两次输出均含未译日文，按失败计分。

在作品内按页配对 bootstrap 2,000 次（seed=20261017），每次对两条件抽取相同页面并重新汇总 corpus 计数。报告 candidate−baseline 差值及 95% 百分位区间。

OCR 同时报严格 NFC CER，以及在 NFC 后仅将全角 ASCII 转半角、去除 Unicode 空白的 CER；保留其他标点与假名。两种口径反映格式差异，不把较低的归一化 CER 当作模型改进。输入替换差值不可相加解释为各阶段的错误占比。

## 人评与检测审计

人评预选 48 个区域：按 seed=20261017，每个测试页至多抽取两个日英均非空区域，四系统评同一组 ID，提供原图及必要日文上下文。评分包括忠实度 0–4、自然度 1–3、严重错误和错误类型；缺评不补造，并按各对比的有效配对数报告。当前归档为单人评分：VNTL−Qwen、OCR−官方日文各 47 对，上下文−无上下文 46 对；人评区间按页配对 bootstrap 2,000 次，seed=20261018。见[评分原件](results/R1/source/ratings_1.json)与[分析](results/R1/analysis/summary.json)。

检测另在开发、测试各前 6 页按文字覆盖率 ≥90%、面积比 ≤4 的几何条件审计。官方文字框不等同于气泡边界，因此不报告气泡 mAP；此审计不替代完整流程的翻译质量评估。

## 结论边界与证据

chrF++ 衡量字词重合，不能单独判断语义、人物关系或名字是否正确。95% 区间未做多重比较校正；连续页面和场景相关性未被页重采样建模，区间可能过窄。单人评分没有评审间一致性估计。少量作品上的结果不支持对漫画总体作显著性或准确率保证。

本目录保留配置与抽样记录、预测、评分和统计结果；完整原始图片、运行日志及历史源码快照未全部随包提供，保存结果的复核不等于完整重跑原实验。
