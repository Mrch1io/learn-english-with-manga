# References and externally installed engines/models

- [OpenMantra](https://github.com/mantra-inc/open-mantra-dataset), revision `59341ad922284a8be219b7784feb5a79779a1447`: manga images, Japanese text and reference translations, **CC BY-NC 4.0**. Full research inputs and records are retained in the author's local archive and are not distributed with the product. The shipped desktop sample retains its [license](presentation/LICENSE.txt) and [attribution](presentation/NOTICE.txt). 

- [Ultralytics](https://github.com/ultralytics/ultralytics), `ultralytics==8.4.178` in `requirements.txt`: YOLO detection and training framework, installed with pip. [`detect()`](vision/detection.py) runs `best.pt` with it and [tools/train.py](tools/train.py) trains with it; no Ultralytics code is copied into this repository. **AGPL-3.0** ([LICENSE](https://github.com/ultralytics/ultralytics/blob/main/LICENSE)). The `best.pt` in the project root was trained with Ultralytics 8.4.127 from Ultralytics' `yolov8m.pt` pretrained weights, and its embedded metadata declares AGPL-3.0.

- [VNTL Llama3 8B v2](https://huggingface.co/lmg-anon/vntl-llama3-8b-v2-hf), revision `7fcc824210daba9fec95b2768d9ecc5ff1b287ab`: Japanese/English translation model. Its model card declares the **Llama 3 license** and supplies the Metadata/Japanese/English translation format. Original card, upstream Llama 3 license and acceptable-use policy are retained under `runtime/vntl/`; the model repository itself does not contain a separate LICENSE file.
- [mradermacher's Q4_K_M GGUF](https://huggingface.co/mradermacher/vntl-llama3-8b-v2-hf-GGUF), revision `1b38b21aa0bbd2861d1f2f7972fb1bd37d3f481c`: community quantization, also declares Llama 3. Exact file `vntl-llama3-8b-v2-hf.Q4_K_M.gguf`, 4,920,735,744 bytes, SHA256 `914f59fcba116d2ac3d3abf77c1b9e95c18e2b3b4e22fd5d88ecffb162bc81ed`. 
- [llama.cpp](https://github.com/ggml-org/llama.cpp/releases/tag/b11706), build `b11706` / commit `f74e2fa6a`: official Windows CUDA 12.4 binary, separately installed under `runtime/llama.cpp/b11706`, **MIT license** retained in `runtime/llama.cpp/LICENSE`. Python uses the documented native HTTP completion API on a task-owned loopback server; it does not use a paid inference provider. CUDA DLLs are reused from the existing GPU PyTorch environment.

- [Koharu](https://github.com/koharu-rs/koharu): selective page processing and proofreading were design references. Its README identifies MIT/Apache-2.0 licensing. No Rust implementation is incorporated here.
- [neartana/manga-translator](https://github.com/neartana/manga-translator): shared CLI/UI processing and preserved input folder structure were design references. No code is incorporated.
- [VOICEVOX Engine](https://github.com/VOICEVOX/voicevox_engine): a separately installed local HTTP service. This project implements calls to its published `/speakers`, `/audio_query` and `/synthesis` APIs with Python's standard library. The downloaded engine retains its own bundled license and resource notices; see [engine LICENSE](https://github.com/VOICEVOX/voicevox_engine/blob/master/LICENSE). Individual voices have their own terms, available in the engine's `/speaker_info?speaker_uuid=...` response. The author's sample voices are credited as **VOICEVOX:四国めたん / VOICEVOX:ずんだもん**. Any redistributed sample audio must retain its corresponding voice attribution; see the [usage guide](USAGE_EN.md#japanese-click-to-listen-and-voices).
- [Magi v2](https://huggingface.co/ragavsachdeva/magiv2), revision `fbc890fec52977142e8ee00bfe26e9458b65517c`: installed separately under `runtime/magiv2`, including its original README and model code. The author states that models/datasets are for **academic research purposes only** in the [official repository](https://github.com/ragavsachdeva/magi#license-and-citation).
